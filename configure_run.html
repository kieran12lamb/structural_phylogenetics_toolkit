Search Parameters (viral-phylo search)

-q / --query

Structure file (.pdb/.cif), UniProt accession, or NCBI protein accession.

-o / --output-dir

Structures are saved under <output-dir>/structures. (default: search_cohort)

-d / --database

Comma-separated list; emits -d for each. (default: bfvd_v3)

--max-hits

Upper ceiling on cohort size after quality filtering. (default: 500)

--max-evalue

Drop hits above this E-value (e.g. 1e-3 or 0.001). (default: 1e-3)

--min-coverage

Minimum aligned fraction of the query protein. (default: 0.0)

--min-aln-length

Minimum alignment length in residues. (default: 0)

--workers

Concurrent structure downloads. (default: 12)

Cohort Partitioning & Quality Control

Similarity Clustering & Recursive Splitting

--cluster-mode

How to partition before aligning. (default: structural)

--cluster-evalue

Foldseek e-value for structural clustering. (default: 1.0)

--cluster-coverage

Alignment coverage required to join a cluster. (default: 0.5)

--cluster-min-seq-id

Used when --cluster-mode sequence. (default: 0.5)

--cluster-tmscore

Use TM-align at this TM-score instead of 3Di+AA. (default: None)

--plm-algorithm

Used when --cluster-mode plm. (default: kmeans)

--plm-k

Fixed k, or leave blank to auto-pick optimal silhouette k.

--plm-k-min / --plm-k-max

Candidate k range for silhouette selection. (default: 2..30)

--cluster-sweep

Subject to --cluster-min-size & --cluster-min-retained.

--cluster-min-size

Min cluster size counted as usable in sweep. (default: 10)

--cluster-min-retained

Fraction of taxa sweep must keep in usable clusters. (default: 0.70)

--min-seq-length

Drop short fragments before clustering. (default: 50)

--min-length-frac

Drop sequences shorter than this × median length. (default: 0.4)

--full-set-max-gap

Reject whole-set alignment above this gap fraction. (default: 0.50)

--full-set-max-expansion

Max multiple of median ungapped length for whole-set. (default: 1.5)

--recurse-max-depth

Max times a gappy cluster may be split. (default: 2)

--recurse-max-gap

Split cluster if its alignment gap fraction reaches this. (default: 0.65)

--recurse-max-expansion

Split cluster if alignment exceeds this × median length. (default: 3.0)
